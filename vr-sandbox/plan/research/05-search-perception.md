# Research: Search, perception modes, and the phone app

One research pass, 2026-10-31, done by a research agent reading public sources (product pages, documentation, papers, benchmarks). These are its findings in short, kept so they are not lost; a line names its source where the research gave one (the full reports, with their links, were returned in the session of 2026-10-31). Where a figure came from a vendor, or from an aggregator rather than the paper itself, the line says so; such figures are claims, not measurements of ours. Nothing here was measured in Nexus unless it says so.

- uFuzzy README bench (162k phrases, 86 queries): uFuzzy ~5ms/q (2.4 w/ prefix cache) no index 28MB heap; FlexSearch ~1ms/q but 3.2s build, 670MB peak; MiniSearch ~17ms/q, 0.5s build; Fuse ~390ms/q (out). Orama: full-text+vector+hybrid in one API (hybridWeights text .7/vector .3 in NearForm example with gte-small 384d). Pagefind wrong shape.
- Embeddings: MiniLM-L6 q8 ~23-35MB via transformers.js; bge-small needs query prefix + CLS pooling; NO phone latency measurement found -> measure. iOS evicts script storage after 7 days idle.
- RRF k=60 (Cormack 2009), insensitive in [20,100].
- Recommended: Tier0 exact trie/sorted names+aliases+codes (<0.2ms); Tier1 MiniSearch fielded boosts, serialized index, Web Worker (or uFuzzy if >3ms); Tier2 semantic only over ~600 nodes+categories, vectors precomputed, query embedded on device lazily, fuse RRF. 70k x384: f32 107MB, int8 27MB, binary 3.4MB.
- Ghost/locomotion: Sci Reports 2025 (n=15) sickness teleport 1.8 < joystick 2.3 < cybershoes 2.9 (1-5). Ghost = collisions off + 6DoF; teleport default, smooth optional, constant velocity, snap turn, vignette. three-mesh-bvh 500 rays vs 80k polys at 60fps.
- Scale: Kim & Interrante 2017 "Dwarf or Giant"; PLOS One 2020 eye height + hand size => giant feeling with IPD fixed. WebXR IPD fixed -> scale world about feet by 1/s; scale speed + near plane; log-space ease 0.5-1s; show "1:50" + reference object.
- Time: Braid (Blow GDC 2010) record every frame; deterministic fixed timestep + timeScale on accumulator; pause=0; rewind ring buffer keyframes (0.5s) + deltas; keep head/hands real-time; Superhot mode optional.
- Sight: pmndrs postprocessing EffectPass merges effects; WebGPU RenderPipeline vs legacy EffectComposer; x-ray fresnel additive depthWrite false; EdgesGeometry threshold; scalar per vertex -> 256x1 colormap texture; viridis for truth, Turbo for thermal look (not perceptually uniform); legend min/max; night vision pass; clippingPlanes + stencil capping; explode offset along centroid.
- JARVIS: Perception (Iron Man 2 phone/glass UIs), Cantina Creative HUDs, Jayse Hansen "HUD Bible"; 5 anchor widgets + situational ones fanning from a core; gaze/voice + pointing. Make It So (Shedroff & Noessel). One hue per mode (cyan navigate, amber warn, magenta time, green sight); glass sparingly; 150-300ms motion; prefers-reduced-motion; View Transitions API.
- Voice: Web Speech (Chrome/Edge/Samsung; Safari 14.5+ webkit prefix; Firefox flag); Chrome 139 processLocally; fallback Moonshine tiny 27M (better than Whisper-base for short commands); small command grammar first; speechSynthesis replies.
- PWA: iOS no install prompt (Share > Add to Home Screen), push only installed 16.4+, iOS 26 "Open as Web App", 7-day eviction; Android install prompt.
- MOOSKY: USPTO reg 6333775 MOOSKY live, class 26 (hair accessories); JP regs classes 8, 20; moosky.ai = AI video/image/voice platform (closest collision, same space); Amazon baskets, fishing lures, Algorand token. No app named Moosky in US App Store. Not legal advice: clearance search advised or variant name.
