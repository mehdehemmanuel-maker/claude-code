- Agent engineering: Anthropic long-running harness: initializer writes init.sh, progress file, git baseline, JSON feature list all failing; each session reads progress+features+git log, one feature, test, commit, clean. Harness design: planner/generator/evaluator; self-grading lenient; skeptical evaluator tuned vs human judgement; few-shot scored examples; sprint contract (27 criteria); 20min/$9 solo vs 6h/$200 harness; later 3h50/$124.70; "every component encodes an assumption"; planner kept. Context engineering: compaction, notes outside window, subagents. Cursor scaling agents: flat peers w/ locks failed (20 agents = 2-3 throughput); optimistic concurrency -> risk-averse churn; planners (recursive) + workers + judge, fresh starts; ~1 week, 1M+ lines; prompts matter more. Spec Kit: constitution; specify->plan->tasks->implement; checklists. Kiro: EARS requirements, design, tasks traceability, steering files, hooks. Devin: Knowledge (triggered, pinned) + Playbooks; ask finished session where budget went. Best supported: external task list starting failing; separate calibrated evaluator; fresh contexts + handoff files; planner/worker hierarchy; executable verifiers over prose.
