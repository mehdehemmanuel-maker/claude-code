# The whole-tree audit — what to delete, redo and edit

Measured, not surveyed. Every number here comes from a command named beside it, and every command is in
`docs/TOOLS.md`. Run 8g did the first four items; the rest is the list, in the order worth doing.

## The instruments this was measured with

| Command | Answers |
| --- | --- |
| `node tools/unwired.mjs` | what is built and nothing can reach |
| `node tools/unwired.mjs path <a> <b>` | whether two parts of the tree know each other at all |
| `npm run tidy` | the tree's own shape: oversize files, name clashes, imports up a layer, stale prose |
| `npm run substrate -- unaccounted` | what a world does not account for: holes, dead ends, unapplied laws |
| `npm run substrate -- time` | every law as the power of time it gives |
| `npm run breakdown` | parts stored but never broken down to materials |

## DONE in Run 8g

1. **`src/ganglia/laws.ts` and `types.ts` deleted — 1,156 lines.** Proved first: it held 155 laws and *all 155*
   are in `src/nexus/book`, so nothing was lost. It was not dead to tests — `tests/nexus/book.test.ts` checked
   the new book's ports, symbols, units, statements and worked examples against it, law by law. **A guard must not
   be a second implementation**, so the guard was kept and its source frozen as data: `tests/nexus/kept-laws.json`,
   155 laws, every field the test reads, including whether a domain predicate existed and that each example sat
   inside its own. 187 tests still pass; the thing they check against can no longer drift or be imported by
   mistake.
2. **One Lewis table, not three.** `engineering/mechanics.ts` held its own copy of Shigley Table 14-2 beside the
   one in `engineering/gears.ts` (a third was in `ganglia/laws.ts` and went with it). `lewisFormFactor` now
   delegates to `lewisY`. Dead exports: **152 → 145.** Unreached files: **30 → 28.**
3. **`docs/ROUNDS.md` split: 3,181 lines → 231.** Over half of it was one section headed *"Now (2026-10-09; read
   before resuming)"* that was a week stale — the exact fault CLAUDE.md was written to cure, reappearing in the
   log CLAUDE.md points at. Now an index, the **seven fault families** (the part actually worth reading), and the
   latest rounds. The history is kept whole and unedited in `docs/rounds/archive-1.md` and `archive-2.md`: a
   round's record is evidence.
4. **The citation rule follows the split.** Three tidy rules read `ROUNDS.md` for blocks of figures that name no
   command. They now read the archives too, so splitting a file cannot become a way to escape the rule.

## TO DELETE — measured, each needs the same proof as item 1 above

**145 dead exports** (named nowhere, tests included) and **28 unreached files**. Do not delete on the count: each
needs the check that killed `ganglia/laws.ts` — *is everything it holds somewhere else?* The ones that look most
like superseded predecessors, biggest first:

- `src/persistence/schema.ts` + `codec.ts` — the old save format; the canonical codec question is whether
  anything still reads a saved file.
- `src/construct/build.ts` — `Solid, Servo, Motor, Pack, Controller, Receiver`, reached by nothing.
- `src/doc/commands.ts` — 10 dead command handlers from the pre-Nexus document model.
- `src/data/life.ts`, `people.ts`, `wood.ts`, `observers.ts` — data files nothing imports.
- `src/nexus/embody/stock.ts` — 10 dead `*_SRC` constants.
- `src/diagnostics/watchdog.ts`, `src/engineering/beams.ts`, `springs.ts`, `welding.ts`.

**12 of the 28 unreached files are `substrate/`** — `attempt`, `clock`, `compose`, `explore`, `hold`, `project`,
`rate`, `scale`, `study-joint`, `study-swing`, `tune`, `holes` (that last one now has a door). These are not debt
of the same kind: they are the physics-native layer, and `clock.ts` in particular is where `substrate/time.ts`
belongs. **Wire, do not delete.**

## TO REDO

1. **The drive line onto the substrate.** `parts/drive.ts` hand-codes `power.rotary` and `inertia.disc`, which the
   book already holds with sources and validity domains — the two-owners fault one level down, in the file written
   to cure it. And `substrate/`'s relations still *bind* addresses, so the state is defined by laws rather than by
   time: the reframe of Run 8f is demonstrated, not adopted.
2. **A `Place` is a box.** `half: [Leaf, Leaf, Leaf]`, `volume = 8h₀h₁h₂`. No sphere, no cylinder, no gear. Every
   shape the parts library can draw is unrepresentable in the reality layer.
3. **`mechanism.ts`'s `JointKind` has had `'gear'` in it since it was written and nothing produces one.**

## TO EDIT

- **41 of 159 prices rest on a search listing, not the seller's own page** (`supply.ts`: 52 weak, by fault —
  41 search listing, 9 out of stock, 4 asked-not-sold, 1 no page). **None are stale by date**; the newest is
  2026-10-13 and the oldest is 4 days old. The fault is provenance, not age, and it is blocked on the network:
  the sellers' size tables render in JavaScript this container cannot run.
- **`docs/OWNERS.md` is 103 lines and 61 KB** — 594 bytes a line. It is a table with paragraphs in its cells, and
  it is unreadable in a terminal.
- **49 files in `docs/`, 23,393 lines.** After the ROUNDS split the next largest are the alignment and autopsy
  reports, several of which describe code that has since been replaced.

## NOT a finding, and worth writing down

The dimensional reduction in `substrate/time.ts` (c = ħ = k_B = 4πε₀ = 1, every quantity a power of time) is
**standard physics** — Planck units, proposed 1899, used daily by every particle physicist. It is not something
CAD systems missed. They do not use it because CAD solves a different problem: static geometry under constraints,
where SI millimetres are exactly right and a dimensionless speed would be useless. What is genuinely unusual here
is the **architecture** — one writer, everything else read-only, with the read-only property machine-tested — not
the physics.
