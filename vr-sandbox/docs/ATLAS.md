# The atlas

Everything the nexus holds, in one place: generated by `atlasText()` in `src/nexus/navigate.ts`; `tests/nexus/docs.ts` fails if it is out of date (write it again with `UPDATE_ATLAS=1 npx vitest run tests/nexus/docs.ts`). In the app, the library's search reaches all of it, and each node shows what could come after and before it.
