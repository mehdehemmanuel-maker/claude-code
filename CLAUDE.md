# This repository

The active project is `vr-sandbox/` (Nexus and its VR forge). Read `vr-sandbox/CLAUDE.md` before working there: it holds
what the user asked for in their own words, which module owns which concern, and the checks
every round must pass. Beside it: `docs/OWNERS.md` (each owner in full), `docs/ROUNDS.md` (what each round did and the
fault it found) and `docs/TOOLS.md` (every tool built for this work).
